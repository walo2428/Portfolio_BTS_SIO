Gestion de Projet — Méthodologie Agile

Server IRIS — Cockpit & Nextcloud

Gestion Utilisateurs & Transfert de Fichiers · Debian 12 · Docker · MariaDB · 4 sprints · Réf. SISR-2025

Cadrage CQQCOQP

Qui

Omar Talibi (SISR) · Nedj, Julien, Rémi, Edib, Saïd, Vincent, Tiago · SLAM (MediaStock) · Tuteur : Yan

Quoi

Cockpit (admin web port 9090) + Nextcloud via Docker Compose + MariaDB (partage fichiers port 8080)

Quand / Combien

Déc. 2025 – Mars 2026 · 4 sprints · 5 semaines effectives

Pourquoi

Fournir une interface d'admin web et une solution de stockage auto-hébergée sans dépendance cloud tiers

Objectifs SMART(E)
S

Spécifique — Déployer Cockpit (port 9090) et Nextcloud (port 8080) avec base MariaDB persistante sur Debian 12.

M

Mesurable — 10 cas de tests définis (T01 à T10) — 9/10 validés en fin de projet.

A

Atteignable — Technologies maîtrisées (Docker, Linux Debian) — 5 semaines avec un objectif par sprint.

T

Temporel — Livrable final validé avant fin mars 2026 — un objectif technique par sprint hebdomadaire.

E

Éthique — Données hébergées en interne, accès restreint aux utilisateurs autorisés, HTTPS prévu.

Gestion des risques

Critique — R1

Perte données Nextcloud — Volumes Docker persistants db_data & nextcloud_data. Vérification survie après docker-compose down/up.

Élevé — R2

Port bloqué par pare-feu — ufw allow 9090/tcp && ufw allow 8080/tcp. Vérification ufw status + netstat -tlnp.

Moyen — R3

Conflit versions Docker — Versions fixes dans docker-compose.yml : mariadb:10.6, nextcloud:27. Éviter les tags "latest".

Faible — R4

Services inaccessibles après reboot — restart: always dans docker-compose.yml + systemctl enable docker.
